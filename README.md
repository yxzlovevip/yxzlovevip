### 关于我

我在这里分享自己做的 Windows 桌面工具，从账号管理到软件安装，让重复操作更简单。

- **开发方向**：Windows 桌面应用与实用工具
- **项目技术**：C# / .NET / WPF / Entity Framework Core / SQLite
- **关注体验**：清晰的界面、便捷的操作与本地数据管理
